The finite thermal and ADC images run independent polling observations in one FreeRTOS task, then use the accepted platform to return to ROM. They reuse the production device drivers and the physically demonstrated PMIC/RTC returning platform. Physical sensor acquisition remains untested.

The thermal image decodes the five factory calibration fields, starts all five sensors and gathers two complete observation sets. The ADC image first obtains an actual shared CLDO3 reservation and reads its setting through the production PMIC provider. It requires enabled CLDO3 selector 13, programmed as 1.8 V, before sampling GPADC0–3. Programmed voltage does not establish measured voltage, stability, input range or source impedance. The ADC image requires separate electrical admission for the routed selection dividers. Thermal execution does not establish that admission.

Each image uses the common clock registry and register mutex. Both reserve the shared ADC clock exclusively, excluding other ADC/thermal consumers throughout the test. The selected APB1 parent/divider is read and validated without retuning. An enabled ADC parent is adopted only at normalized SYS24 or direct 24 MHz DCXO. Cold setup chooses direct DCXO for a 24 MHz oscillator and normalized SYS24 for 26 or 19.2 MHz. The shared reference decoder and pinned manual section 4.1.6.170 define those choices. ADC peripheral clock admission now matches the existing thermal implementation, including the reserved PERI0 bit 24.

The clients accumulate valid channels across service calls. A second set requires new contributions after the first set completes. Thermal set time and sequence identify the final contributing read; ADC records each channel's observation time. These are latest-value observations, without simultaneous-sampling or lossless-event claims. Signed thermal millidegrees Celsius use sign-extended two's-complement hexadecimal fields. ADC code zero is valid; there is no voltage or strap interpretation.

The client deadline is 1.5 seconds, within the unchanged monitor's two-second recovery interval. Observation ends 100 milliseconds before the driver sampling deadline of 1.2 seconds. Successful configured disable reads back conversion and local interrupt enables as disabled. It does not establish analog drain. IRQ70 remains masked and inactive during ADC sampling; its expected pending bit may remain latched and is reported. Thermal IRQ71 remains masked, inactive and unpending. Neither image configures the distributor, takes over USB, starts secondaries or changes supply voltages.

The linked checks execute actual client, counter conversion, driver, native filters, registry and mutex instructions. The ADC check also executes the actual PMIC state machine and rail/pin managers. Scheduling, queue primitives, architectural observations and MMIO effects are modeled. The cases include partial-channel accumulation, normalized clock adoption/setup, invalid clock/calibration/supply state, inherited activity, missing samples, expected ADC pending IRQ and thermal IRQ loss after mutex acquisition. Separate sanitized ADC clock cases cover 24, 26 and 19.2 MHz start/read/stop. Existing unchanged monitor and device arithmetic evidence is reused.

Thermal completion text is `COMPLETE native thermal configured disable`; ADC completion text is `COMPLETE native ADC configured disable`. Require normal monitor cleanup, copied RAM log, RAM restoration and responsive ROM return. Stop at the first transport failure or disappearance. There is no automatic retry or reset.

Completion text and status zero establish normal configured-disable termination. Functional success additionally requires `THERMAL_OUTCOME` or `ADC_OUTCOME` equal to zero, two complete sets and the device PASS marker. Outcome one reports insufficient complete sets after configured disable. Uncertainty exits with status one and no completion marker, preserving fault diagnostics and retained ownership.

Both success and failure retain resources. Thermal retains its clock token, parent/bus enable and reset-release settings, acquisition/filter/period configuration and factory corrections. ADC retains its ADC/parent clock token, CLDO3 token, PMIC lifetime, TWI/pin reservations and controller configuration; its completed PMIC request is reaped. ADC pending IRQ70 may remain set. No reset, clock disable, lease release or peripheral restoration is claimed. Subsequent overlapping peripheral use requires reviewed continuity or confirmed whole-board power removal. ROM responsiveness alone grants no peripheral reuse. Accuracy, interrupts, thermal protection policy and broader ADC modes remain unqualified.
